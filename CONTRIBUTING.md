# Contributing to tinytask

Thanks for helping. tinytask is small on purpose, so changes should stay small
and easy to review.

## Claiming an issue

1. Comment on the issue to say you would like to work on it.
2. Wait for a maintainer to assign it to you before you start.
3. If you can no longer work on it, say so on the issue so someone else can
   pick it up. Claims with no activity for 48 hours may be released.

One open claim per person at a time, please, until your first pull request is
merged.

## Making a change

1. Fork the repository and create a branch.
2. Make your change and add or update tests in `tests/`.
3. Run the tests: `python3 -m pytest`.
4. Open a pull request that says `Fixes #<issue number>` in its description.

## Pull requests we will close

- Pull requests with no linked issue, unless they fix a typo.
- Pull requests that change many unrelated files.
- Pull requests generated by AI tools that the author has not run or tested.
  Using AI to help is fine; sending code you have not checked is not.

## Getting help

Ask in the `#help` channel on our Discord. Be specific: say which issue you
are on, what you tried, and what happened.
